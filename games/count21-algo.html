Step 1 · 觀察必輸位置
以經典設定 目標=21、M=2（每次最多報2個）為例，從尾端往回推：

距離目標 1 步時輪到你 → 只能報到21 → ❌ 你輸（L）
距離 2 步時輪到你 → 報1個，讓對手距離1步 → ✅ 你贏（W）
距離 3 步時輪到你 → 報2個，讓對手距離1步 → ✅ 你贏（W）
距離 4 步時輪到你 → 報1剩3(W)、報2剩2(W)，對手怎麼都贏 → ❌ 你輸（L）
距離 5~6 步時 → 可以讓對手距離4步(L) → ✅ 你贏（W）
距離 7 步時 → 報1剩6(W)、報2剩5(W) → ❌ 你輸（L）
🔍 規律 必輸距離：1, 4, 7, 10, 13, 16, 19 …
換算成實際數字（目標21）：必輸時「目前數到」= 0, 3, 6, 9, 12, 15, 18
每隔 M+1 = 3 出現一次，和 Bachet 完全一樣的結構。
Step 2 · 和 Bachet 的對應關係
21點報數和 Bachet's Game 表面上完全不同，但數學結構一模一樣。
只要做一個變數替換，就能把一個問題轉換成另一個：
21點報數 對應 Bachet's Game
目前報到 current ↔ 已取走的石頭數
剩餘距離 = target - current ↔ 剩餘石頭數 n
報 1~M 個數字 ↔ 取 1~M 顆石頭
說到目標數字者輸 ↔ 取走最後一顆者輸
💡 關鍵洞察 把 Bachet 的「剩幾顆石頭」換成「距離目標還有幾步」，兩個問題完全等價。
這就是為什麼學會一個，另一個就自動會了——同一個數學，兩個包裝。
Step 3 · DP 推導（用「剩餘距離」定義）
定義 dp[d] = 距離目標還有 d 步時，當前玩家的狀態（W/L）
轉移規則和 Bachet 完全一樣。
Python 
# DP 填表（target=21, M=2，以「剩餘距離」為狀態）
dp[0] = False  # 距離0：輪到你時對手剛說完21，你已贏——邊界定義
dp[1] = False  # 只能報1個到達目標 → 你輸 (L)
dp[2] = True   # 報1個 → 對手距離1(L) → 你贏 (W)
dp[3] = True   # 報2個 → 對手距離1(L) → 你贏 (W)
dp[4] = False  # 報1→dp[3]=W, 報2→dp[2]=W → 你輸 (L)
dp[5] = True   # 報1 → dp[4]=L → 你贏 (W)
dp[6] = True   # 報2 → dp[4]=L → 你贏 (W)
dp[7] = False  # 報1→dp[6]=W, 報2→dp[5]=W → 你輸 (L)
# L位置：1, 4, 7, 10 … 每 M+1=3 一個週期

# 轉換回「目前數到幾」：必輸時 current = target - d
# d=1→current=20, d=4→current=17, d=7→current=14 …
# 所以必輸的 current 值：0, 3, 6, 9, 12, 15, 18（= target % (M+1) 的倍數）
Step 4 · O(1) 公式與必勝策略
L-position 對應到「剩餘距離 % (M+1) == 1」，
等價於「(target - current) % (M+1) == 1」。

必勝走法：讓對手面對下一個 L-position。
Python 
def is_losing(current: int, target: int, M: int) -> bool:
    remaining = target - current
    return remaining % (M + 1) == 1   # O(1)

def best_count(current: int, target: int, M: int) -> int:
    remaining = target - current
    K = M + 1
    r = remaining % K
    if r == 1 or r == 0:
        return 1              # 敗局（r==1）或邊界，隨便報
    return min(r - 1, M)   # 報 r-1 個，讓對手剩餘距離 % K == 1

# 例子：target=21, M=2, current=0
# remaining=21, K=3, r=0 → 敗局（先手必輸！）
# 對手報1→remaining=20, r=2 → 後手報1個補成3 → 先手又面對倍數
Step 5 · 驗證：完整走一局（目標=21, M=2）
K = M+1 = 3，必輸的「目前數到」= 0, 3, 6, 9, 12, 15, 18

開局 current=0，(21-0) % 3 = 0，距離是3的倍數 → 先手必輸

後手策略（每輪讓合計報數 = M+1 = 3）：
先手報 後手報 數到 狀態
1個（到1）2個（到3） 3L ✗
1個（到4）2個（到6） 6L ✗
…… 18L ✗
1個（到19）2個（到21） 21先手被迫說21 ✗
✅ 結論 先手必輸條件：(target - 0) % (M+1) == 0，即 target 是 M+1 的倍數
必勝策略：每輪讓合計報數 = M+1，把 L-position 一路傳給對手。
本質上和 Bachet 的 n % (M+1) == 1 是同一回事，只是換了坐標系。
