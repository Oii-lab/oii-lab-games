Step 1 · 遊戲結構和 Nim 的相似性
Turning Turtles 看起來和 Nim 完全不同，但其實是 Nim 的變體。

每回合規則：選一隻朝上的烏龜翻面（必翻），同時可以翻它左邊任意一隻。

關鍵觀察：必翻的那隻烏龜一定要從朝上變朝下（位置「消失」），
附加翻轉可以是朝上→朝下，也可以是朝下→朝上。

這和 Nim 的「從某堆取石頭」有深刻的對應關係——我們接下來一步步說明。
Step 2 · Sprague-Grundy 定理回顧
在 Nim 的解析頁我們提過：任何組合賽局都有一個 Grundy value，
多個獨立子遊戲合在一起時，整體 Grundy value = 各子遊戲 XOR。

Turning Turtles 可以被視為每隻烏龜都是一個獨立的子遊戲，
整體的勝負由所有子遊戲的 Grundy value XOR 決定。
💡 關鍵問題 每隻烏龜（在它的位置上）的 Grundy value 是多少？
解決這個問題，就能用 XOR 決定整場遊戲的勝負。
Step 3 · 計算每隻烏龜的 Grundy value
把烏龜從右邊開始編號（1-indexed）：最右邊是位置 1，往左依序增加。

考慮只有一隻朝上的烏龜在位置 k 的情況：
Python 
# 只有位置 k 的烏龜朝上（從右 1-indexed）
# 可以做的操作：
# 1. 只翻位置 k：朝上→朝下，到達終局（G=0）
# 2. 翻位置 k + 翻位置 j（j < k）
#    - 若位置 j 朝下：翻後朝上，局面變成「位置 j 朝上」= G(j)
#    - 若位置 j 朝上（本例中只有位置k朝上，j沒有朝上的）

# 從位置 k 可以到達的狀態：
# - 終局 G=0（只翻k）
# - G(1), G(2), ..., G(k-1)（翻k + 翻左邊位置j，使j朝上）

# mex({0, G(1), G(2), ..., G(k-1)})
# 用數學歸納法：
G(1) = mex({0}) = 1
G(2) = mex({0, G(1)}) = mex({0, 1}) = 2
G(3) = mex({0, G(1), G(2)}) = mex({0, 1, 2}) = 3
# 規律：G(k) = k
✅ 結論 位置 k（從右 1-indexed）的朝上烏龜，Grundy value = k
朝下的烏龜 Grundy value = 0（不影響遊戲）

這和 Nim 的「一堆 k 顆石頭的 Grundy value = k」完全一樣！
Step 4 · 整體 XOR 策略
由 Sprague-Grundy 定理，整體 Grundy value = 所有朝上烏龜位置的 XOR：
Python 
def grundy_xor(turtles: list) -> int:
    # turtles[i] = True 表示第 i 隻（從左0-indexed）朝上
    n = len(turtles)
    xor = 0
    for i, up in enumerate(turtles):
        if up:
            pos = n - i  # 從右 1-indexed
            xor ^= pos
    return xor

# XOR = 0 → 當前玩家必輸
# XOR ≠ 0 → 當前玩家必贏，找讓 XOR=0 的走法

def best_move(turtles: list):
    n = len(turtles)
    xor = grundy_xor(turtles)
    if xor == 0: return None  # 敗局

    for main in range(n):
        if not turtles[main]: continue
        pos_main = n - main

        # 只翻 main
        new_xor = xor ^ pos_main  # 去掉 main
        if new_xor == 0: return (main, -1)

        # 翻 main + 翻左邊 extra
        for extra in range(main):
            pos_extra = n - extra
            new_xor2 = xor ^ pos_main ^ pos_extra  # 去掉main，toggle extra
            if new_xor2 == 0: return (main, extra)

    return None
Step 5 · 完整走一局
以 8 隻烏龜，位置 2, 5, 7 朝上（從右 1-indexed）為例：
局面（朝上位置） Grundy XOR 走法 狀態
{2, 5, 7} 2⊕5⊕7 = 0 ⚠️ 先手在敗局，隨便走 L
{2, 5} 或其他 ≠ 0 後手找讓 XOR=0 的走法 W
… 後手每步都能恢復 XOR=0 最終後手翻下最後一隻 後手贏 ✓
🔗 和 Nim 的完美對應 Turning Turtles 本質上就是多堆 Nim！
每隻朝上的烏龜對應一堆石頭，石頭數 = 烏龜從右的位置編號。
「翻下 + 附加翻轉」= 「取石頭 + 調整另一堆」的操作。
所以策略完全一樣：保持 Grundy XOR = 0 給對手。
