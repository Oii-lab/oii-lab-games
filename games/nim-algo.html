Step 1 · 為什麼單堆的方法在多堆失效
Bachet's Game 用的是 n % (M+1) 的週期規律。
但多堆 Nim 每次可以從任意一堆取任意數量，情況完全不同：

比如 [3, 5]，你能取第一堆的3顆、也能取第二堆的1顆……沒有固定的「步長」可以套用模運算。

這時候需要一個能同時描述多個數字狀態的工具——XOR（位元互斥或）。
Step 2 · XOR 的關鍵性質
XOR 有兩個對這個問題至關重要的性質：
Python 
# 性質1：a XOR a = 0（自我抵消）
5 ^ 5 == 0   # True

# 性質2：a XOR 0 = a（與0 XOR 不變）
5 ^ 0 == 5   # True

# 把每個數字寫成二進位，對每個位元獨立看：
#  3 = 011
#  5 = 101
#  6 = 110
# XOR = 000  ← 每個位元上 1 的個數都是偶數 → Nim-sum = 0

#  1 = 001
#  2 = 010
#  4 = 100
# XOR = 111 = 7  ← 每個位元上都是奇數個 1 → Nim-sum ≠ 0
💡 直覺 把各堆石頭數量「疊加」在二進位上，XOR 就是看每個位元有幾個 1。
偶數個 1 → 那個位元 XOR 為 0，奇數個 1 → XOR 為 1。
Nim-sum = 0 代表每個位元都「配對」了，是一種「平衡」狀態。
Step 3 · Bouton 定理與必勝策略
📐 Bouton 定理（1901年） Nim-sum = 0 → 當前玩家必輸
Nim-sum ≠ 0 → 當前玩家必贏
為什麼 Nim-sum = 0 必輸？

從 Nim-sum = 0 出發，不管你從哪一堆取幾顆，那一堆的數字一定會改變，
至少有一個位元被動到，所以取完後 Nim-sum 一定不等於 0。
對手永遠從 Nim-sum ≠ 0 的狀態開始，你永遠從 Nim-sum = 0 的狀態開始。
最終所有石頭被取光（Nim-sum = 0），輪到你——你輸。
為什麼 Nim-sum ≠ 0 必贏？

Nim-sum ≠ 0，表示存在某個最高位的 1。
找到那個最高位，找一堆在那個位上也是 1 的堆，
從那堆取走適當數量，讓那堆和 Nim-sum XOR 之後比原來小，
取完後整體 Nim-sum 就變成 0，把必輸局面傳給對手。
Python 
def nim_best_move(heaps: list) -> tuple:
    nim_sum = 0
    for h in heaps:
        nim_sum ^= h

    if nim_sum == 0:
        # 敗局，隨便取一顆（對手完美時必輸）
        i = next(i for i, h in enumerate(heaps) if h > 0)
        return (i, 1)

    for i, h in enumerate(heaps):
        target = h ^ nim_sum    # 取完後這堆應剩幾顆
        if target < h:          # 只有減少才合法
            return (i, h - target)  # 取走 h-target 顆
Step 4 · 完整走一局（[3, 5, 7]）
初始局面：[3, 5, 7]
Nim-sum = 3 XOR 5 XOR 7 = 011 XOR 101 XOR 111 = 001 = 1 ≠ 0 → 先手必贏
局面 Nim-sum 走法 狀態
[3, 5, 7] 1 ≠ 0 先手從堆3取1顆（7→6） W ✓
[3, 5, 6] 0 後手任意取 L ✗
… ≠ 0 先手恢復 Nim-sum=0 W ✓
[0, 0, 1] 0（Misère） 後手被迫取最後一顆 後手輸 ✗
✅ 驗證 3 XOR 5 XOR 6 = 011 XOR 101 XOR 110 = 000 = 0 ✓
先手每次都能把 Nim-sum 恢復成 0，後手永遠面對 Nim-sum ≠ 0。
Step 5 · Sprague-Grundy 定理（進階）
為什麼 XOR 能用？背後有更深的理論：Sprague-Grundy 定理。

每個遊戲狀態都有一個 Grundy value（或稱 nimber），定義為：
G(狀態) = mex({ G(可到達的狀態) })
其中 mex 是「最小不存在的非負整數」。

對於 Nim 的單堆：G(n顆) = n（因為從n顆可以到0,1,...,n-1，mex = n）

多個獨立子遊戲合在一起時：整體 G = 各子遊戲 G 的 XOR。
這就是為什麼多堆 Nim 的勝負完全由 XOR 決定！
Python 
from functools import lru_cache

def grundy(n: int, moves: set) -> int:
    """計算任意遊戲的 Grundy value"""
    @lru_cache(maxsize=None)
    def g(state):
        reachable = {g(state - m) for m in moves if m <= state}
        mex = 0
        while mex in reachable:
            mex += 1
        return mex
    return g(n)

# Nim 單堆：moves = {1,2,3,...,n}（可取任意數）
# G(0)=0, G(1)=1, G(2)=2, G(3)=3 ... G(n)=n

# 多堆 [3,5,7]：G = 3 XOR 5 XOR 7 = 1 ≠ 0 → 先手必贏
# 多堆 [3,5,6]：G = 3 XOR 5 XOR 6 = 0 → 當前玩家必輸
🔬 重要性 Sprague-Grundy 讓你能分析任意組合賽局，不只是 Nim。
只要能算出每個子遊戲的 Grundy value，XOR 起來就知道輸贏。
這是組合賽局理論最核心的定理。
Step 6 · Misère 規則的調整
我們的遊戲用的是 Misère 規則（取最後一顆者輸），和標準 Nim（取最後一顆者贏）略有不同。

Misère Nim 的策略只在接近結局時需要調整：
情況 標準 Nim Misère Nim
存在大於1的堆 Nim-sum = 0 → 必輸 Nim-sum = 0 → 必輸（相同）
全部都是 0 或 1 的堆 1的堆數為奇數 → 必贏 1的堆數為奇數 → 必輸（相反）
💡 記憶口訣 中盤和標準 Nim 完全一樣，只有到「全是1的堆」時反轉。
直覺上，全是1的堆意味著每人每輪只能取1顆，最後一個取的人輸，
所以奇數堆時你是「最後取」的人。
