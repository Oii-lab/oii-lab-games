Step 1 · 問題定義
有 n 件物品，每件有重量 w[i] 和價值 v[i]。
背包容量為 W，每件物品只能取一次（0 或 1），求最大總價值。

形式化：選一個子集 S，使得 Σw[i] ≤ W 且 Σv[i] 最大。
物品 重量 價值 價值/重量
⚔️ 寶劍5102.0
💎 寶石263.0
⛑️ 頭盔6111.8
🧪 藥水133.0
⚠️ 貪心失效 「每次取價值/重量最高的」不一定對。
容量 W=8：貪心取寶石(2)+藥水(1)+寶劍(5)=重8，價值19。
但最優是寶石(2)+藥水(1)+頭盔(6)=重9，超了！
所以最優是寶劍(5)+寶石(2)+藥水(1)=重8，價值19——這次貪心剛好對，但不總是。
Step 2 · 暴力搜尋：為什麼行不通
最直接的想法：枚舉所有子集，找最大價值且不超重的那個。
Python 
def brute_force(items, W):
    n = len(items)
    best = 0
    for mask in range(1 << n):  # 2^n 種子集
        w = v = 0
        for i in range(n):
            if mask & (1 << i):
                w += items[i].w
                v += items[i].v
        if w <= W: best = max(best, v)
    return best

# 時間複雜度：O(2^n × n)
# n=20：約 2000 萬次，還行
# n=40：約 1 兆次，太慢
# n=100：根本跑不完
Step 3 · DP 的核心思維
DP 的關鍵：把大問題拆成小問題，避免重複計算。

考慮第 i 件物品，只有兩種選擇：
・不選：問題變成「前 i-1 件物品，容量 W」的子問題
・選（前提是 w[i] ≤ W）：問題變成「前 i-1 件物品，容量 W-w[i]」再加上 v[i]

這兩個子問題都比原問題小，而且可能被重複用到——存起來就是 DP。
💡 最優子結構 背包問題有「最優子結構」：整體最優解包含子問題的最優解。
這是 DP 能用的必要條件——如果子問題的最優解組合起來不是整體最優，DP 就不能用。
Step 4 · 轉移方程與填表
定義 dp[i][w] = 前 i 件物品、容量 w 時的最大價值：
Python 
# 邊界條件
dp[0][w] = 0  # 沒有物品，價值為0
dp[i][0] = 0  # 容量為0，什麼也放不下

# 轉移方程
if w < items[i].w:
    dp[i][w] = dp[i-1][w]          # 放不下，只能不選
else:
    dp[i][w] = max(
        dp[i-1][w],               # 不選第 i 件
        dp[i-1][w - items[i].w] + items[i].v  # 選第 i 件
    )

# 完整實作
def knapsack(items, W):
    n = len(items)
    dp = [[0]*(W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(W+1):
            dp[i][w] = dp[i-1][w]
            if w >= items[i-1].w:
                dp[i][w] = max(dp[i][w],
                    dp[i-1][w - items[i-1].w] + items[i-1].v)
    return dp[n][W]

# 時間複雜度：O(n × W)
# 空間複雜度：O(n × W)，可優化到 O(W)
Step 5 · 回溯找出最優解
dp 表填完後只知道最大價值，還需要「回溯」找出選了哪些物品：
Python 
def traceback(dp, items, W):
    selected = []
    w = W
    for i in range(len(items), 0, -1):
        if dp[i][w] != dp[i-1][w]:
            # 第 i 件被選了（否則值應該和上一行一樣）
            selected.append(i-1)
            w -= items[i-1].w
    return selected

# 從最後一行往回追蹤：
# 如果 dp[i][w] != dp[i-1][w]，代表第 i 件被選了
# 然後容量減去該物品重量，繼續往上追蹤
📐 空間優化 如果只需要最大價值（不需要回溯），可以把 dp 壓縮成一維：
dp[w] = max(dp[w], dp[w - items[i].w] + items[i].v)
注意：要從大到小更新 w，避免同一件物品被選多次。
