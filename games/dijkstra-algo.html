Step 1 · 為什麼 BFS 在有權重的圖上不行？
BFS 找的是「跳數最少」的路徑，當每條邊的權重相同時，跳數最少 = 距離最短。
但當邊有不同權重時，跳數少的路不一定距離短。
反例：S → T
路徑一：S → A → T   跳數 2，距離 1+1=2
路徑二：S → B → T   跳數 2，距離 3+3=6
路徑三：S → T       跳數 1，距離 10
BFS 選「跳數1」的 S→T，但距離最短是「跳數2」的 S→A→T。
💡 結論 BFS 適合無權重圖或所有邊權重相同的圖。
有不同權重時，需要 Dijkstra。
Step 2 · Dijkstra 核心：Relaxation（鬆弛）
Dijkstra 的核心操作叫 Relaxation（鬆弛）：

對於邊 (u, v, w)，如果 dist[u] + w < dist[v]，就更新 dist[v]。
意思是：「透過 u 到達 v，比目前已知的路徑更短」。
Dijkstra 的執行流程：
1 初始化：起點距離設為 0，其餘設為 ∞，全部加入 Priority Queue
2 從 PQ 取出距離最小的節點 u（Greedy 選擇）
3 對 u 的所有鄰居 v 做 Relaxation：若 dist[u]+w < dist[v]，更新 dist[v]
4 重複步驟 2-3，直到 PQ 為空
🔑 Greedy 正確性 每次從 PQ 取出距離最小的節點時，這個距離已經是最終最短距離，不可能再被縮短。
這是因為所有邊權重都是非負數——如果有負邊，Dijkstra 就不保證正確。
Step 3 · 完整程式碼
Python 
import heapq

def dijkstra(graph, start):
    # graph: {node: [(neighbor, weight), ...]}
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    prev = {node: None for node in graph}

    # Priority Queue: (distance, node)
    pq = [(0, start)]

    while pq:
        d, u = heapq.heappop(pq)  # 取出距離最小的

        if d > dist[u]:  # 過期的條目，跳過
            continue

        for v, w in graph[u]:
            if dist[u] + w < dist[v]:  # Relaxation
                dist[v] = dist[u] + w
                prev[v] = u
                heapq.heappush(pq, (dist[v], v))

    return dist, prev

# 還原路徑
def get_path(prev, start, end):
    path = []
    cur = end
    while cur is not None:
        path.append(cur)
        cur = prev[cur]
    return path[::-1]  # 反轉
💡 過期條目的處理 Python 的 heapq 不支援修改已在 heap 裡的元素，所以當 dist[v] 更新時，舊的 (old_dist, v) 還留在 heap 裡。
取出時用 if d > dist[u]: continue 跳過這些過期條目，這是最常見的實作方式。
Step 4 · 複雜度分析
實作方式 時間複雜度 適合場景
陣列（線性掃描最小值） O(V²) 稠密圖（邊多）
Binary Heap（heapq） O((V+E) log V) 稀疏圖（一般情況）
Fibonacci Heap O(E + V log V) 理論最優，實作複雜少用
💡 實務上 競程和面試幾乎都用 Binary Heap，即 heapq，複雜度 O((V+E) log V) 就夠用。
V = 節點數，E = 邊數，log V 來自 heap 的 push/pop 操作。
Step 5 · 限制與延伸：負邊權、Bellman-Ford
Dijkstra 的致命限制：不能有負邊權。
若有負邊，取出節點後仍可能被縮短距離，Greedy 正確性不成立。
例：A→B=5, A→C=3, C→B=-4，Dijkstra 先取 B（距離5），但正確答案是 A→C→B=3-4=-1。
演算法 負邊 複雜度 備註
Dijkstra ❌ 不行 O((V+E) log V) 最常用
Bellman-Ford ✅ 可以 O(VE) 可偵測負環
Floyd-Warshall ✅ 可以 O(V³) 所有點對最短路徑
