Step 1 · 觀察必輸位置
先從小的情況開始想（以 M=3 為例，每次最多取3顆）：

剩 1 顆時輪到你 → 只能取走最後1顆 → ❌ 你輸（L）
剩 2 顆時輪到你 → 取1顆，讓對手面對1顆 → ✅ 你贏（W）
剩 3 顆時輪到你 → 取2顆，讓對手面對1顆 → ✅ 你贏（W）
剩 4 顆時輪到你 → 取3顆，讓對手面對1顆 → ✅ 你贏（W）
剩 5 顆時輪到你 → 取1剩4(W)、取2剩3(W)、取3剩2(W)，對手怎麼都贏 → ❌ 你輸（L）
剩 6~8 顆時輪到你 → 可以取到讓對手剩5顆(L) → ✅ 你贏（W）
剩 9 顆時輪到你 → 取1剩8(W)、取2剩7(W)、取3剩6(W) → ❌ 你輸（L）
🔍 規律浮現 必輸位置（L-position）：1, 5, 9, 13, 17, 21 …
每隔 M+1 = 4 出現一次。這不是巧合，下面我們來證明它。
Step 2 · 用 DP 嚴格證明
光靠觀察不夠嚴謹，用動態規劃（DP）來確認規律是否永遠成立。

定義 dp[n] = 剩 n 顆時，當前玩家的狀態（W 必贏 / L 必輸）

轉移規則：
・若存在某個取法 k（1 ≤ k ≤ M），使得 dp[n-k] = L，則 dp[n] = W
・若所有取法都讓對手進入 W，則 dp[n] = L
Python 
# DP 填表（M=3，True=必贏W / False=必輸L）
dp[0] = False  # 0顆：輪到你時對手已取走最後一顆，你贏了——但這裡定義為L是為了轉移方便
dp[1] = False  # 只能取1顆 → 取走最後一顆 → 輸 (L)
dp[2] = True   # 取1 → dp[1]=L，讓對手輸 → 贏 (W)
dp[3] = True   # 取2 → dp[1]=L → 贏 (W)
dp[4] = True   # 取3 → dp[1]=L → 贏 (W)
dp[5] = False  # 取1→dp[4]=W, 取2→dp[3]=W, 取3→dp[2]=W → 全都贏不了 (L)
dp[6] = True   # 取1 → dp[5]=L → 贏 (W)
dp[7] = True   # 取2 → dp[5]=L → 贏 (W)
dp[8] = True   # 取3 → dp[5]=L → 贏 (W)
dp[9] = False  # 取1→dp[8]=W, 取2→dp[7]=W, 取3→dp[6]=W → (L)
# L位置：1, 5, 9, 13 … 完全吻合，每 M+1=4 一個週期 ✓

# 完整 DP 實作
def solve(N: int, M: int) -> list:
    dp = [False] * (N + 1)
    for n in range(2, N + 1):
        dp[n] = any(not dp[n - k] for k in range(1, min(M, n) + 1))
    return dp
Step 3 · 為什麼週期是 M+1
DP 確認了規律，但為什麼週期偏偏是 M+1？

關鍵在於：兩人輪流取，每輪一定會取走 至少2顆、最多2M顆。
但如果你能每輪控制合計恰好 = M+1，就掌握了節奏：

對手取 k 顆（1 ≤ k ≤ M）
你取 M+1-k 顆（同樣合法，因為 1 ≤ M+1-k ≤ M）
一輪結束，石頭恰好減少 M+1 顆。
💡 核心直覺 從一個 L-position 出發，每輪減 M+1，下一個 L-position 還是你的對手面對。
L-position 之間距離固定是 M+1，所以整條數線上每隔 M+1 就出現一個 L。

反之，如果你在 W-position，一定能找到一個取法跳到下一個 L-position，
讓對手陷入必輸局面。
Step 4 · 推出 O(1) 公式
L-position 序列是 1, M+2, 2(M+1)+1, 3(M+1)+1, …
統一表示為：n = 1 + j*(M+1)，其中 j = 0, 1, 2, …

因此：n % (M+1) == 1 ↔ 必輸（L-position）
Python 
def is_losing(n: int, M: int) -> bool:
    return n % (M + 1) == 1   # O(1) 判斷

def best_move(n: int, M: int) -> int:
    if n == 1:
        return 1              # 已是敗局，被迫取走
    K = M + 1
    r = n % K
    if r == 1:
        return 1              # 在 L-position，隨便取（此局必輸）
    take = r - 1 if r > 0 else K - 1
    return max(1, min(take, M, n - 1))
    # 取完後 n' % (M+1) == 1，把 L-position 傳給對手
Step 5 · 驗證：完整走一局（N=21, M=3）
K = M+1 = 4，L-position = 1, 5, 9, 13, 17, 21

開局 21 顆，21 % 4 = 1 → 先手在 L-position，先手必輸

後手策略（每輪補到合計4顆）：
先手取 後手取 剩餘 狀態
任意 k4-k17 L ✗
任意 k4-k13 L ✗
任意 k4-k9 L ✗
任意 k4-k5 L ✗
任意 k4-k1 先手被迫取走 ✗
✅ 結論 先手必輸條件：N % (M+1) == 1
必勝策略：每輪讓合計取走 = M+1，把 L-position 一路傳給對手。
時間複雜度：O(1) 判斷勝負，O(1) 計算最優走法。
