Step 1 · 觀察必輸位置
先從小的情況開始想（M=3，每次最多取3顆）：

剩 1 顆時輪到你 → 只能取走最後1顆 → 你輸
剩 2 顆時輪到你 → 取1顆，對手剩1顆必輸 → 你贏
剩 3 顆時輪到你 → 取2顆，對手剩1顆必輸 → 你贏
剩 4 顆時輪到你 → 取3顆，對手剩1顆必輸 → 你贏
剩 5 顆時輪到你 → 取1剩4(W)、取2剩3(W)、取3剩2(W)，對手怎麼都贏 → 你輸
🔍 規律浮現 必輸位置：1, 5, 9, 13, 17, 21 …
每隔 M+1 = 4 出現一次，這不是巧合！
Step 2 · 用 DP 嚴格證明
直覺看到規律了，但怎麼確定後面也成立？用動態規劃（DP）來嚴格推導。

定義 dp[n] = 剩 n 顆時，當前玩家是 W（必贏）還是 L（必輸）。

轉移規則很直接：
・若存在某個取法 k（1≤k≤M），使得 dp[n-k] = L，則 dp[n] = W（我能讓對手必輸）
・若所有取法都讓對手 W，則 dp[n] = L（我怎麼走都輸）
Python 
# DP 填表（M=3，以 True=必贏W / False=必輸L 表示）
dp[0] = False  # 0顆：無石可取，上一個人取走最後一顆輸了，此時輪到你已經贏了
dp[1] = False  # 1顆：只能取1顆 → 取走最後一顆 → 輸(L)
dp[2] = True   # 2顆：取1 → dp[1]=L，對手輸 → 贏(W)
dp[3] = True   # 3顆：取2 → dp[1]=L → 贏(W)
dp[4] = True   # 4顆：取3 → dp[1]=L → 贏(W)
dp[5] = False  # 5顆：取1→dp[4]=W, 取2→dp[3]=W, 取3→dp[2]=W → 全輸(L)
dp[6] = True   # 6顆：取1 → dp[5]=L → 贏(W)
dp[7] = True   # 7顆：取2 → dp[5]=L → 贏(W)
dp[8] = True   # 8顆：取3 → dp[5]=L → 贏(W)
dp[9] = False  # 9顆：取1→dp[8]=W, 取2→dp[7]=W, 取3→dp[6]=W → 全輸(L)
# L位置：1, 5, 9, 13 … 完全吻合，每 M+1=4 一個週期
Step 3 · 理解為什麼是週期 M+1
關鍵在於：每次兩人合計取走的顆數，可以從 2 到 2M，但不管怎樣，
只要你每次都讓一輪合計 = M+1，就能控制局面。

對手取 k 顆，你取 (M+1-k) 顆，一輪結束後石頭減少恰好 M+1。
只要從 L-position 出發，每輪減 M+1，對手永遠面對下一個 L-position。
💡 核心直覺 你的目標是「控制節奏」：不管對手取幾顆，你都能補到一輪合計 M+1。
這樣石頭數就按 …→ 1+(M+1)k 的規律遞減，對手永遠踩在必輸格。
Step 4 · 從規律推出 O(1) 公式
DP 跑完之後，L-position 就是 1, M+2, 2(M+1)+1, …
統一寫成：n % (M+1) == 1 時必輸。

必勝走法也很直接：
Python 
def best_move(n: int, M: int) -> int:
    if n == 1:
        return 1          # 已是敗局，被迫取走
    K = M + 1
    r = n % K
    if r == 1:
        return 1          # 已在 L-position，隨便取（此局必輸）
    take = r - 1 if r > 0 else K - 1
    return max(1, min(take, M, n - 1))
    # 取完後讓 n' % (M+1) == 1，把 L-position 留給對手
Step 5 · 驗證：回看剛才那局
以經典設定 N=21、M=3 來驗證：

K = M+1 = 4，L-position = 1, 5, 9, 13, 17, 21
開局 21 顆，21 % 4 = 1 → 先手在 L-position，先手必輸！

後手策略：不管先手取幾顆，後手都補到一輪合計4顆：
先手取1→後手取3（剩17）、先手取2→後手取2（剩17）、先手取3→後手取1（剩17）
每輪後，石頭數都停在 L-position：17 → 13 → 9 → 5 → 1，先手被迫取走最後一顆。
✅ 結論 先手必輸的條件：N % (M+1) == 1
必勝策略：每輪讓合計取走數 = M+1，把 L-position 一路傳給對手。
