Step 1 · O(n²) 三兄弟：Bubble · Selection · Insertion
三種都是 O(n²)，但各有特色：
🔴 Bubble Sort
相鄰兩兩比較，大的往右「冒泡」。最直觀但最慢。
🟡 Selection Sort
每輪掃描找最小值放到前面。交換次數最少（O(n)），但比較次數固定 O(n²)，不穩定。
🟢 Insertion Sort
像插撲克牌，從第二個開始往前插入正確位置。最好情況 O(n)（幾乎排好時），小資料或幾乎有序時最實用。
Python 
# Bubble Sort
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

# Insertion Sort
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
Step 2 · Merge Sort：分治法保證 O(n log n)
核心思想：分而治之。把陣列對半拆，各自排好，再合併。
合併兩個已排序陣列只需要 O(n)，而遞迴深度是 O(log n)，所以總共是 O(n log n)。
Python 
def merge_sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    left  = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:  # ≤ 保證穩定性
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    return result + left[i:] + right[j:]

# 時間：O(n log n) 任何情況
# 空間：O(n)（需要額外陣列）
# 穩定：✅
💡 為什麼是 O(n log n)？ 每層遞迴總共處理 n 個元素（合併的工作量），共有 log n 層，所以是 n × log n。
Step 3 · Quick Sort：平均最快但有最壞情況
選一個 pivot，把比它小的放左邊，大的放右邊（partition），再遞迴兩側。
原地排序（不需要額外陣列），常數因子小，實際上最快。
Python 
def quick_sort(arr, lo, hi):
    if lo >= hi: return
    pivot_idx = partition(arr, lo, hi)
    quick_sort(arr, lo, pivot_idx - 1)
    quick_sort(arr, pivot_idx + 1, hi)

def partition(arr, lo, hi):
    pivot = arr[hi]  # 選最後一個為 pivot
    i = lo - 1
    for j in range(lo, hi):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i+1], arr[hi] = arr[hi], arr[i+1]
    return i + 1

# 平均：O(n log n)，最壞（已排序）：O(n²)
# 解法：隨機選 pivot，或三數取中
⚠️ 最壞情況 如果每次 pivot 都選到最大或最小值（例如已排序的陣列選最後一個），遞迴深度變 O(n)，整體變 O(n²)。
解法：隨機選 pivot，或選頭、中、尾的中位數（三數取中）。
Step 4 · 為什麼 O(n log n) 比 O(n²) 快這麼多？
n（資料量） O(n²) O(n log n) 快了幾倍
100 10,000 665 15×
1,000 1,000,000 9,966 100×
10,000 100,000,000 132,877 753×
1,000,000 10¹² 19,931,568 50,000×
💡 直覺理解 n=100 萬時，O(n²) 要做 1 兆次操作，O(n log n) 只要 2000 萬次。
假設每秒 10 億次：O(n²) 要 1000 秒，O(n log n) 只要 0.02 秒。
Step 5 · 何時用哪個？實際應用
情境 推薦 原因
資料量小（n < 20） Insertion Sort 常數因子小，小資料最快
幾乎已排序 Insertion Sort 最好情況 O(n)
需要穩定排序 Merge Sort 唯一穩定的 O(n log n)
一般用途、最快 Quick Sort 平均最快，原地排序
實際語言內建 Timsort / Introsort Python 用 Timsort（Merge+Insertion），C++ 用 Introsort（Quick+Heap+Insertion）
