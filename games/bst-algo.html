Step 1 · BST 定義與性質
二元搜尋樹（Binary Search Tree）是一種特殊的二元樹：

對每個節點 N：
・左子樹的所有值 < N 的值
・右子樹的所有值 > N 的值
・左右子樹也各自是 BST

這個性質讓搜尋可以每次排除一半的可能，達到 O(log n)。
💡 和二元搜尋的關係 BST 的結構就是把「二元搜尋」的過程固定在樹的形狀裡。
在陣列上做二元搜尋 O(log n)，在 BST 上搜尋也是 O(log n)——但 BST 還支援動態插入和刪除。
Step 2 · 插入與搜尋
插入和搜尋的邏輯完全一樣：比較後往左或往右走。
Python 
class BSTNode:
    def __init__(self, val):
        self.val = val
        self.left = self.right = None

def insert(node, val):
    if not node: return BSTNode(val)  # 找到空位，插入
    if val < node.val:
        node.left = insert(node.left, val)   # 往左
    elif val > node.val:
        node.right = insert(node.right, val)  # 往右
    # val == node.val: 不插入（BST 不重複）
    return node

def search(node, val):
    if not node: return False          # 找不到
    if val == node.val: return True    # 找到！
    if val < node.val: return search(node.left, val)
    return search(node.right, val)

# 時間複雜度：O(h)，h = 樹高
# 平衡時 h = log n → O(log n)
# 最壞時 h = n   → O(n)
Step 3 · 刪除：三種情況
刪除是 BST 最複雜的操作，分三種情況：
情況一：葉節點（無子節點）
直接移除，不影響其他節點。
刪除 4：
   5   →   5
  /        /
  3        3
   \         \
    4         （移除）
情況二：單子節點
用唯一的子節點取代被刪除的節點。
刪除 3：
   5   →   5
  /        /
  3        4
   \
    4
情況三：雙子節點（最複雜）
找右子樹的最小值（中序後繼），用它的值取代，然後刪除那個最小值節點。
Python 
def delete(node, val):
    if not node: return None
    if val < node.val:
        node.left = delete(node.left, val)
    elif val > node.val:
        node.right = delete(node.right, val)
    else:  # 找到了，判斷哪種情況
        if not node.left: return node.right   # 情況一或二
        if not node.right: return node.left   # 情況二
        # 情況三：找右子樹最小值（中序後繼）
        successor = node.right
        while successor.left:
            successor = successor.left
        node.val = successor.val              # 用後繼值取代
        node.right = delete(node.right, successor.val)
    return node
Step 4 · 中序走訪 = 排序
BST 的中序走訪（左→根→右）結果永遠是由小到大排序的！
這是 BST 性質的直接推論。
Python 
def inorder(node, result=[]):
    if not node: return
    inorder(node.left, result)   # 先走左子樹（小的）
    result.append(node.val)       # 記錄根節點
    inorder(node.right, result)  # 再走右子樹（大的）
    return result

# 例：插入 [5,3,7,1,4,6,8] 後
# inorder → [1, 3, 4, 5, 6, 7, 8]（已排序！）

# 時間複雜度：O(n)（每個節點走訪一次）
# 空間複雜度：O(h)（遞迴深度）
🔗 Tree Sort 把 n 個數字全部插入 BST，再做中序走訪，就完成了排序。
平均複雜度 O(n log n)，和 Merge Sort 一樣——但常數較大，實際用途有限。
Step 5 · 最壞情況與平衡樹
BST 的致命弱點：插入順序決定樹形。
插入順序 樹高 搜尋複雜度
[4,2,6,1,3,5,7]（平衡） 3 O(log n)
[1,2,3,4,5,6,7]（遞增） 7 O(n) 😱
隨機順序 ≈ log n O(log n) 平均
🌳 解法：平衡 BST 為了保證 O(log n)，需要在插入/刪除後自動平衡：
・AVL Tree：嚴格平衡，每次操作後旋轉調整
・Red-Black Tree：近似平衡，C++ STL 的 map/set 就是用它
・B-Tree：多路平衡，資料庫索引常用
