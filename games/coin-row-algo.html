Step 1 · 貪心策略為什麼失效
第一直覺：「每次取左右兩端較大的那個」，也就是貪心策略。
但這是錯的，一個反例就能推翻它：
硬幣：3, 5, 1, 15, 2, 4

貪心策略（每次取較大端）：
玩家取 4（右）→ 電腦取 3（左）→ 玩家取 2（右）→ 電腦取 5（左）→ 玩家取 15（右）→ 電腦取 1（左）
玩家得分：4+2+15 = 21，電腦得分：3+5+1 = 9

看起來贏了？但如果電腦也用最優策略：
玩家取 4（右）→ 電腦取 3（左）→ 玩家取 15（右，現在應取！）→ …

最優策略：玩家取 3（左）→ 電腦取 4（右）→ 玩家取 5（左）→ 電腦取 2（右）→ 玩家取 15（左）→ 電腦取 1（右）
玩家得分：3+5+15 = 23，電腦得分：4+2+1 = 7
💡 關鍵洞察 你取的每一步都會影響對手能取什麼，進而影響你下一步能取什麼。
這種「當前決策影響未來選項」的問題，貪心看不到全局，必須用 DP。
Step 2 · 遞迴思維：縮小問題規模
DP 的起點是「把大問題拆成小問題」。

面對硬幣 coins[i..j]，當前玩家有兩種選擇：
・取左端 coins[i] → 對手面對 coins[i+1..j]
・取右端 coins[j] → 對手面對 coins[i..j-1]

對手也是最優玩家，所以對手會讓我接下來能拿的最少。
我的總得分 = 現在取的 + 對手走完後我能取的最多。
Python 
def best_score(coins, i, j) -> int:
    """當前玩家在 coins[i..j] 中能拿到的最大分數"""
    if i > j: return 0
    if i == j: return coins[i]

    # 取左端：對手面對 [i+1..j]，對手最優後我面對較差的那個
    take_left = coins[i] + min(
        best_score(coins, i+2, j),   # 對手取了 i+1
        best_score(coins, i+1, j-1)  # 對手取了 j
    )

    # 取右端：對手面對 [i..j-1]
    take_right = coins[j] + min(
        best_score(coins, i+1, j-1),  # 對手取了 i
        best_score(coins, i, j-2)    # 對手取了 j-1
    )

    return max(take_left, take_right)
⚠️ 問題 這個遞迴有大量重複計算，複雜度是指數級的。
解法：把計算過的結果存起來——這就是 Memoization，也是 DP 的核心。
Step 3 · 區間 DP：定義與轉移
把遞迴的結果存在二維表格裡：
Python 
# dp[i][j] = 當前玩家在 coins[i..j] 中能拿到的最大分數

# 邊界條件
dp[i][i] = coins[i]   # 只剩一枚，全拿
dp[i][j] = 0  if i > j  # 沒有硬幣

# 轉移方程
dp[i][j] = max(
    coins[i] + min(dp[i+2][j], dp[i+1][j-1]),  # 取左端
    coins[j] + min(dp[i+1][j-1], dp[i][j-2])   # 取右端
)
為什麼是 min？
取左端 coins[i] 後，對手面對 [i+1..j]，對手也最優，
對手會讓我剩下的最少（對手取 i+1 或 j，留給我較差的那個）。
所以我能保證拿到的是：coins[i] + min(dp[i+2][j], dp[i+1][j-1])
Step 4 · 完整填表過程
以 coins = [3, 5, 1, 4] 為例，填 dp 表：
i\j j=0 (3) j=1 (5) j=2 (1) j=3 (4)
i=0 3 5 6 7
i=1 — 5 5 9
i=2 — — 1 4
i=3 — — — 4
dp[0][3] = 7：先手最多能拿 7 點，後手拿 3+5+1+4-7 = 6 點，先手贏。

驗算 dp[0][3]：
取左(3)：3 + min(dp[2][3], dp[1][2]) = 3 + min(4, 5) = 7 ✓
取右(4)：4 + min(dp[1][2], dp[0][1]) = 4 + min(5, 5) = 9 ✗（怎麼比 7 大？）

實際上取右(4) = 9 才是最優！先手取右4，再取左5，得到 9 點。
✅ 填表順序 必須從短區間往長區間填（len=1 → len=2 → … → len=n），
因為長區間的計算依賴短區間的結果。
Step 5 · 複雜度分析
Python 
def coin_row_dp(coins: list) -> int:
    n = len(coins)
    if n == 0: return 0
    dp = [[0] * n for _ in range(n)]

    # 長度 1
    for i in range(n):
        dp[i][i] = coins[i]

    # 長度 2 到 n
    for length in range(2, n+1):
        for i in range(n - length + 1):
            j = i + length - 1
            take_left = coins[i] + min(
                dp[i+2][j] if i+2 <= j else 0,
                dp[i+1][j-1] if i+1 <= j-1 else 0
            )
            take_right = coins[j] + min(
                dp[i+1][j-1] if i+1 <= j-1 else 0,
                dp[i][j-2] if i <= j-2 else 0
            )
            dp[i][j] = max(take_left, take_right)

    return dp[0][n-1]  # 先手能拿到的最大分

# 時間複雜度：O(n²)（填 n×n 的表，每格 O(1)）
# 空間複雜度：O(n²)（dp 表）
策略 時間 空間 最優
貪心O(n) O(1)❌ 不一定
暴力遞迴O(2ⁿ) O(n)✅ 是
區間 DPO(n²) O(n²)✅ 是
